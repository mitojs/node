共享诊断内核

    架构边界

    人和 AI Agent 共用执行能力

    TUI 使用 React / Ink；机器接口由 Commander 提供结构化 JSON。二者共用执行器与插件，TUI 仅在交互模式加载。

    指标通道与诊断通道

    CPU / Memory 优先读取新鲜 Agent 指标，可回退 Inspector。Profile、Heap Snapshot、进程报告与代码执行使用 Inspector。错误和定时器依赖 SDK / Agent。

    内存指标与文件分别归属

    Rust Agent 的指标存储位于守护进程内存。CLI 管理文件产物和持久化历史。Shared 包是 SDK / CLI 的进程内代码依赖。
